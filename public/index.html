02 — Набор для проектов

Следуй бренду Bor.

Правила, ресурсы и инструменты, которые можно взять в новый проект.

Установите навык bor-brand для Codex. В новом проекте напишите «Следуй бренду Bor» — навык возьмёт знак и правила из набора и поможет встроить их в существующий интерфейс.

Подключить навык

Распакуйте архив и выполните из каталога с папкой bor-brand:

python bor-brand/scripts/brand.py install-skill

Навык доступен со следующего сообщения в Codex. Экспорт работает локально, без сети; нужен Python 3.9+.

identity
Базовый профиль. Знак b∅r и правила Bor. Обязательные для всех продуктов шрифт, UI-палитра и отступы пока не выбраны.
devices
По выбору: Geist, монохромные темы и значения оформления из Devices. Для новых продуктов используется, когда нужен именно этот стиль.

Что можно взять

Веб: SVG, CSS, пример HTML. Android: векторы и foreground иконки. В профиле devices — также лицензированный шрифт, CSS-переменные и Kotlin-токены для Compose. Подключение выполняется с учётом устройства проекта.

04 — Правила

Сохранять суть.

Правила в PDF ↗
Написание
В тексте — Bor. В графике — b∅r. Bybor и ByBor не используются как имя бренда.
Состав знака
Только b∅r. Без маленького by, адреса, подписи и дополнительных элементов внутри логотипа.
Геометрия
Один рисунок для всех носителей. Масштабировать пропорционально, сохранять поля. Менять цвет под фон, не растягивать по осям.
Подпись автора
by Bor означает «сделано Бором». Это отдельный текст рядом со знаком. Подпись продукта — Devices by Bor.
Малые экраны
В иконке приложения и на OLED — только b∅r. Размер и поля подбираются под носитель, геометрия остаётся общей.
